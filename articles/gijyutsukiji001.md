# 一問一答のAIアプリはもう古い？LangGraph.jsで『ライター×レビュアー』の自律推敲ループをReactに実装する方法

プログラミング学習を進め、「JavaScriptやReactの基本構文は学んだ」「単発のAPI呼び出し（一問一答）でAIにテキストを出力させる方法は分かった」という段階のWeb開発者・個人開発者が次に直面する壁――それが「単なる一発出しの生成AIツールから脱却し、生成物のクオリティを自動的に担保する仕組みをどう組むか」という課題です。

従来のAIチャットのように1回のプロンプトで長文や技術記事を作成しようとすると、コードの脱落や説明の飛び、論理の不備が生じやすくなります。人間が文章を書くときと同じように、「ライターが執筆し、編集者が客観的な基準で添削（赤入れ）を行い、それを受けて書き直す」という推敲プロセスをプログラム上で全自動化すること――これこそが、近年急速に注目を集めている「AIエージェント（Agentic AI）」の考え方です。

この記事では、Reactと最新のAIフレームワークを組み合わせて、自律的に質の高い文章を作り出す次世代のWebアプリ開発手法の核心をご紹介します。

---

## 1. 従来のAIアプリ（一問一答）が抱える限界

これまでのAIアプリ開発では、ユーザーがプロンプトを1回送り、AIが1回回答を返すという「一問一答」のスタイルが主流でした。
しかし、技術記事やドキュメントのように正確性が求められるコンテンツを自動生成する場合、次のような問題に直面します。

* **コードの脱落や論理の飛躍:** 一度の出力では、コードブロックの閉じ忘れや説明の不足が発生しやすい。
* **品質のばらつき:** プロンプトをどれだけ工夫しても、モデルの1発書きに依存するため、人間による大掛かりな修正が後から必要になる。

この課題を根本から解決するのが、**状態（State）を持ち、AI同士が協調してループを回すマルチエージェントシステム**です。

---

## 2. LangGraph.jsで「ライター×レビュアー」の自律推敲ループを組む

ここで強力な武器となるのが、グラフ構造でAIのワークフローを定義できる **LangGraph.js** です。

LangGraph.jsを使うと、「ノード（各処理の役割）」と「エッジ（処理の流れ・分岐条件）」をコードで自由に設計できます。具体的には、以下のような Stateful Loop（状態を持つループ）を構築します。

1. **ライターAI（Writer Node）:** テーマに沿ってMarkdown形式の初稿、またはレビュアーからの指摘を反映した再執筆を行う。


2. **レビュアーAI（Reviewer Node）:** 絶対基準（即時NG判定）やカテゴリ別評価チェックリストに照らし合わせて記事を厳格にチェックし、判定（`【OK】` または `【NG】`）と具体的な修正指示を出力する。


3. **継続判定エッジ（shouldContinue）:** レビュアーが `【OK】` を出した場合、または試行回数が上限（3回など）に達した場合は終了（`END`）し、未達かつループ内の場合は再度ライターノードへ差し戻す。



この仕組みにより、**「人間が行っている編集・推敲のプロセス」をプログラム上で完全に再現**することが可能になります。

---

## 3. 実装のイメージ（LangGraphエージェントの核心）

実際に、Reactアプリのバックボーンとなるエージェントロジックの構築イメージは以下の通りです。

```javascript
import { StateGraph, END, START } from "@langchain/langgraph";
import { ChatGoogleGenerativeAI } from "@langchain/google-genai";
import { HumanMessage } from "@langchain/core/messages";

// 1. グラフ全体で共有するステートのスキーマ定義
const graphState = {
  topic: { value: (x, y) => y ?? x, default: () => "" },
  draft: { value: (x, y) => y ?? x, default: () => "" },
  reviewFeedback: { value: (x, y) => y ?? x, default: () => "" },
  iterationCount: { value: (x, y) => y ?? x, default: () => 0 },
};

// 2. 継続判定（ループを続けるか終了するか）
function shouldContinue(state) {
  const feedback = state.reviewFeedback || "";
  const count = state.iterationCount || 0;
  if (feedback.includes("【OK】") || count >= 3) {
    return "end";
  }
  return "retry"; // 要修正の場合はライターノードへ戻る
}

```

高速かつ超低コストで知られる **Gemini 2.5 Flash-Lite** などのモデルをバックエンドに組み合わせることで、複数回のループ処理が発生しても数秒〜十数秒でストレスなく高品質な原稿を完成させることができます。

## 4. 単なるスクリプトから「実用的なWebプロダクト」へ

AIエージェントのロジックが組めれば、次はそれをユーザーが快適に扱えるWebアプリケーションへ昇華させます。

* **フロントエンド:** Vite + React 18 と Bootstrap 5 を用いた洗練されたマルチページUI（記事生成画面・一覧画面）の構築。


* **データベース連携:** Cloud Firestore を用いて、生成された高品質なMarkdown原稿を自動保存・一覧表示・詳細参照・削除（CRUD）できる仕組み。


* **本番のセキュリティ:** Firebase Cloud Functions と Secret Manager を活用し、フロントエンドにAPIキーを露出させないプロ仕様のバックエンド秘匿化設計。



「AIの仕組みを学ぶ」だけでなく、「それをデータベースに保存して管理できる1つのWebプロダクトとして完成させる」ことこそが、個人の開発力を飛躍的に高める鍵となります。
